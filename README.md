Welcome to the repository for my personal portfolio website! This site showcases my background, skills, featured projects, IEEE publications, and certifications.

**🌐 Live Site:** [https://kmanivignesh.github.io/Portfolio/](https://kmanivignesh.github.io/Portfolio/)

## 🚀 Features

- **Modern & Responsive UI:** Clean, glassmorphism-inspired design that works seamlessly on desktop and mobile.
- **3D Interactive Backgrounds:** Powered by **Three.js** to create immersive, tech-inspired visual scenes (constellations, data streams, neural networks).
- **Dynamic Content:** Showcasing projects across Full-Stack Web, AI/ML, and IoT domains.
- **Automated Deployment:** Set up with a **GitHub Actions CI/CD pipeline** to automatically build and deploy via Vite on every push.

## 🛠️ Tech Stack

- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Build Tool / Bundler:** [Vite](https://vitejs.dev/)
- **Deployment:** GitHub Pages (via GitHub Actions)

## 💻 Running Locally

If you'd like to run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kmanivignesh/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   Make sure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173`.
